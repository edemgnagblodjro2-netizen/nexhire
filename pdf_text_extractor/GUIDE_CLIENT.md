## 1. Accès et connexion

### Première connexion

Votre organisation partenaire (ex. : CCI3R) vous envoie un **lien d'invitation unique** de la forme :

```
https://myportal.nexhire.ca/inscription?partenaire=cci3r
```

Ce lien vous relie automatiquement à votre organisation. Sans ce lien, l'inscription n'est pas disponible.

**Étapes :**

1. Cliquez sur le lien reçu par courriel
2. Sur la page d'accueil, choisissez l'onglet **Créer un compte**
3. Remplissez : nom complet, courriel, mot de passe, numéro de téléphone
4. Cliquez **Créer mon compte**
5. Vérifiez votre courriel et cliquez le lien de confirmation
6. Reconnectez-vous : vous serez automatiquement redirigé vers votre espace de travail

### Connexions suivantes

Rendez-vous sur **myportal.nexhire.ca/inscription**, onglet **Se connecter**, entrez votre courriel et mot de passe.

### Mot de passe oublié

Sur la page de connexion → **Mot de passe oublié** → entrez votre courriel → suivez le lien reçu par courriel.

## 3. Tableau de bord

Le tableau de bord est votre page d'accueil. Il affiche une synthèse de votre organisation :

- **Score de maturité IA** — votre score IMAI sur 100, avec niveau (Débutant / Intermédiaire / Avancé)

## 4. Diagnostic IA IMAI

Le **Diagnostic de maturité IA (IMAI)** évalue votre organisation sur 7 dimensions clés de l'intelligence artificielle en environ 10 minutes.

### Lancer un diagnostic

1. Menu latéral → **Diagnostic IA IMAI**
2. Cliquez **Nouveau diagnostic**
3. Entrez le nom de votre entreprise, secteur d'activité et taille
4. Répondez aux questions — chaque section couvre une dimension IA
5. Cliquez **Terminer le diagnostic** pour obtenir votre score

### Les 7 dimensions évaluées

| Dimension | Ce qui est mesuré |
|---|---|
| Données | Qualité, gouvernance et accessibilité de vos données |
| Processus | Automatisation et maturité opérationnelle |
| Technologies | Outils, infrastructure et stack technologique |
| Talents | Compétences IA disponibles dans l'équipe |
| Stratégie | Vision et plan IA de la direction |
| Éthique & Gouvernance | Politiques de gestion responsable de l'IA |
| Communications | Adoption interne et gestion du changement |

### Interpréter votre score

| Score | Niveau | Signification |
|---|---|---|
| 0–40 | Débutant | Premiers pas dans l'IA — fondations à construire |
| 41–70 | Intermédiaire | Initiatives en cours — accélérer les bonnes pratiques |
| 71–100 | Avancé | Maturité IA établie — optimiser et innover |

### Résultats et rapport

Après le diagnostic, vous pouvez :
- Consulter le détail de chaque dimension
- Télécharger un **rapport PDF** de synthèse
- Accéder aux **recommandations personnalisées** d'ATLAS
- Comparer votre score avec les diagnostics précédents

## 5. ATLAS AI — votre conseiller IA

**ATLAS** est votre copilote IA disponible 24h/24. Il analyse vos données, comprend votre contexte organisationnel et vous guide dans votre transformation numérique.

### Ce qu'ATLAS peut faire

- ATLAS tient compte de vos données de diagnostic si vous en avez complété un
- Chaque conversation est contextuelle à votre organisation

## 6. Gouvernance & Conformité Loi 25

### Gouvernance & Loi 25

Ce module vous aide à respecter la **Loi 25 du Québec** (protection des renseignements personnels) et à mettre en place une gouvernance IA responsable.

**Fonctionnalités :**
- Tableau de bord de conformité Loi 25
- Évaluation des risques liés aux données personnelles
- Génération de politiques de confidentialité
- Suivi des incidents et des demandes d'accès

### Conformité Causale

Visualisez l'état de conformité de votre organisation à travers plusieurs cadres réglementaires :

- **ISO 27001** — Sécurité de l'information
- **Loi 25** — Protection des renseignements personnels (Québec)
- **ISO 42001** — Gouvernance de l'IA

Pour chaque non-conformité détectée, la plateforme fournit :
- La **cause racine** identifiée
- Les **preuves** disponibles
- Le **coût de l'inaction** estimé
- Un **plan d'action** généré automatiquement

### Politiques Vivantes

Gérez vos politiques internes liées à l'IA et aux données :
- Créez et activez des politiques (confidentialité, usage de l'IA, sécurité)
- Définissez des règles de vérification automatique
- Suivez le statut de chaque politique (Active / En attente / Violation)

## 7. Centre d'intégrations

Connectez AgentHub à vos outils existants pour enrichir l'analyse IA avec vos données réelles.

### Connecteurs disponibles

| Catégorie | Outils supportés |
|---|---|
| Microsoft | Microsoft 365, Intune |
| Collaboration | Google Workspace, Slack |
| ITSM | Jira, ServiceNow, Zendesk |
| CRM | Salesforce, HubSpot |
| Finance | QuickBooks, SAP, NetSuite |
| RH | Workday, BambooHR, ADP |
| Gestion de projet | Asana, Monday, ClickUp |
| Cloud | AWS |

### Connecter Microsoft 365 (recommandé en premier)

Microsoft 365 est le connecteur le plus puissant — il donne à ATLAS accès à vos licences, utilisateurs, activité Teams, OneDrive et Exchange.

1. Menu latéral → **Centre d'intégrations** → **Microsoft 365**
2. Cliquez **Connecter**
3. Connectez-vous avec un compte **administrateur** Microsoft 365
4. Accordez les permissions demandées
5. Attendez la synchronisation initiale (~2 minutes)

> **Important :** La connexion doit être faite par un compte avec droits administrateur sur votre tenant Microsoft 365.

### Connecter d'autres outils

La procédure est similaire pour tous les connecteurs OAuth (Jira, Google, Slack, HubSpot) :

1. Cliquez sur le connecteur → **Connecter**
2. Vous êtes redirigé vers la page d'autorisation du service
3. Connectez-vous et accordez les permissions
4. Retour automatique sur la plateforme

Pour les connecteurs par clé API (SAP, Workday, etc.) :
1. Cliquez **Entrer les identifiants**
2. Copiez la clé API depuis le portail du service
3. Collez-la dans le champ et enregistrez

### Tester une connexion

Après connexion, cliquez **⚡ Tester** pour vérifier que le connecteur fonctionne correctement.

## Questions fréquentes

**Q : Mes données sont-elles sécurisées ?**  
Oui. Toutes les données sont hébergées au Canada, chiffrées en transit (TLS 1.3) et au repos (AES-128). Chaque organisation est strictement isolée — aucune donnée n'est partagée entre organisations.

**Q : Puis-je utiliser la plateforme sans connecter mes outils ?**  
Oui. Vous pouvez compléter un diagnostic et utiliser ATLAS sans aucun connecteur. Les connecteurs enrichissent les analyses avec vos données réelles mais ne sont pas obligatoires.

**Q : Comment modifier le nom ou le logo de mon organisation ?**  
Menu latéral → **Paramètres** → section Organisation.

**Q : Le diagnostic est-il confidentiel ?**  
Oui. Votre score et vos réponses ne sont visibles que par les membres de votre organisation. Votre organisation partenaire (ex. CCI3R) peut voir un résumé agrégé anonymisé pour le programme.

**Q : Puis-je refaire un diagnostic ?**  
Oui, autant de fois que vous le souhaitez. Chaque diagnostic est archivé et vous pouvez suivre votre progression dans le temps.

**Q : Comment exporter mes données ?**  
Menu latéral → **Rapports & Exports**. Vous pouvez également exercer votre droit d'accès ou de suppression en contactant dpo@nexhire.ca (délai : 30 jours, conformément à la Loi 25).
