Architecture de sécurité NexHire

Conçu avec la sécurité entreprise dès la première ligne de code.

🔐 JWT ES256 🛡️ Fernet AES-128 📊 Audit log immuable 🏛️ Loi 25 / LPRPDE
🔐

Authentification JWT ES256

Tokens signés par courbe elliptique — ES256. Non falsifiables, expiration automatique, vérifiés à chaque requête API.

🛡️

Chiffrement OAuth Fernet

Tous les tokens OAuth sont chiffrés AES-128-CBC + HMAC avant stockage. Jamais lisibles en clair, même par NexHire.

🏢

Isolation multi-tenant

Chaque organisation est cloisonnée par organization_id. Aucun accès croisé entre tenants n'est architecturalement possible.

📋

Audit log immuable

Chaque action est tracée avec IP, timestamp et utilisateur. Le log est append-only — aucune modification possible après écriture.

👥

RBAC à 4 niveaux

Rôles user → manager → admin → owner vérifiés côté serveur à chaque endpoint. Le frontend n'a aucune autorité.

🔒

Mots de passe bcrypt

Hashés avec bcrypt — jamais stockés en clair. Le sel est unique par utilisateur et intégré dans le hash.
