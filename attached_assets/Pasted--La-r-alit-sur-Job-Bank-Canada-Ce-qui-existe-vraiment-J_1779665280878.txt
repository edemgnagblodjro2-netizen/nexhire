📋 La réalité sur Job Bank Canada
Ce qui existe vraiment
Job Bank partage les offres postées directement sur leur plateforme avec d'autres tableaux d'affichage via un flux XML — pas une API REST publique. Si tu veux afficher leurs offres sur ton site, tu dois faire une demande d'accès à leur flux XML.

🔴 Ce que j'avais dit était partiellement inexact
❌ Ce que j'ai dit :
"GET https://www.jobbank.gc.ca/api/jobposting — API publique gratuite"

✅ La réalité :
Pas d'API REST publique libre d'accès.
C'est un flux XML sur demande, avec approbation requise.

✅ Comment ça fonctionne vraiment — 3 options

Option 1 — Flux XML Job Bank (officiel)
Job Bank offre un flux XML de leurs offres d'emploi aux job boards partenaires. Tu peux en faire la demande via leur page réseau — c'est gratuit mais nécessite une approbation.
Processus :
1. Aller sur jobbank.gc.ca/network
2. Remplir le formulaire de demande de partenariat
3. Attendre l'approbation (quelques jours à semaines)
4. Recevoir un lien vers le flux XML
5. Parser le XML dans server.js et insérer en DB

Format des données reçues :
<jobposting>
  <title>Développeur React</title>
  <employer>Entreprise XYZ</employer>
  <location>Montréal, QC</location>
  <salary>85000</salary>
  <description>...</description>
  <date>2026-05-24</date>
  <url>https://jobbank.gc.ca/jobposting/12345</url>
</jobposting>

Avantages :
✅ 100% légal — accord officiel
✅ Gratuit
✅ Vraies offres canadiennes
✅ Mises à jour régulières

Inconvénients :
⏳ Délai d'approbation
📋 Processus administratif
🔗 Redirection vers Job Bank pour postuler
   (le candidat ne postule pas via Nexhire)

Option 2 — Talent.com / Neuvoo API (recommandée pour Nexhire)
Talent.com est le plus grand agrégateur de jobs au Canada.
Ils offrent une API partenaire pour les job boards.

Processus :
1. S'inscrire sur talent.com/publishers
2. Obtenir une clé API (quelques jours)
3. Appels REST simples

Exemple d'appel :
GET https://api.talent.com/rest/jobs
  ?k=développeur
  &l=Montréal
  &lang=fr
  &country=ca
  &api_key=TON_API_KEY

Option 3 — Adzuna API (la plus simple à tester)
API publique avec clé gratuite, disponible immédiatement.

1. S'inscrire sur developer.adzuna.com
2. Obtenir app_id + api_key instantanément
3. Appeler l'API

Exemple :
GET https://api.adzuna.com/v1/api/jobs/ca/search/1
  ?app_id=TON_APP_ID
  &app_key=TON_API_KEY
  &results_per_page=20
  &what=developer
  &where=Montreal
  &content-type=application/json

Avantages :
✅ Clé API immédiate — pas de délai
✅ Données Canada disponibles
✅ JSON propre et bien documenté
✅ Gratuit jusqu'à 1000 appels/jour

Inconvénients :
⚠️ Redirection pour postuler
⚠️ Moins d'offres françaises

const cron = require('node-cron')

cron.schedule('0 */6 * * *', async () => {
  console.log('🔄 Sync jobs externes...')
  
  const res = await fetch(
    `https://api.adzuna.com/v1/api/jobs/ca/search/1
    ?app_id=${process.env.ADZUNA_APP_ID}
    &app_key=${process.env.ADZUNA_API_KEY}
    &results_per_page=50
    &content-type=application/json`
  )
  
  const data = await res.json()
  
  for (const job of data.results) {
    // Insérer seulement si pas déjà en DB
    await db.run(`
      INSERT OR IGNORE INTO jobs 
      (external_id, title, company, location, salary, 
       description, apply_url, source, posted_at)
      VALUES (?, ?, ?, ?, ?, ?, ?, 'adzuna', ?)
    `, [
      job.id,
      job.title,
      job.company.display_name,
      job.location.display_name,
      job.salary_max,
      job.description,
      job.redirect_url,
      job.created
    ])
  }
  
  console.log(`✅ ${data.results.length} jobs synchronisés`)
})
